# 局限性与适用边界

本文件说明本系统"能做什么、不能做什么、结论在什么范围内成立"。
所有条目均基于实际实现与实测结果，不做推测性夸大。

## 1. 数据规模与代表性

- 测试集来自公开数据集 `anilbhujel/viewpoint-aware-pig-posture-recognition` 的 **seen-VP test**
  划分，通过逐实例 bbox 裁切得到单猪图像。样本量见 `data/manifest.csv`
  （目标 120–200 条，实际数量以构建结果为准）。
- **类别严重不均衡**：原划分中 `sitting` 仅占 2.7%（70/2603 实例）。
  经过配额选图后，坐姿样本数仍然偏少，其 Precision/Recall/F1 的置信区间很宽，
  **不能据此断言模型"识别不了坐姿"**，只能说明在本次样本量下表现如何。
- 数据来自 2 个猪栏、8 台固定相机（鱼眼 + RGB 深度相机），**不覆盖**其它猪场、
  其它品种、其它光照与栏舍布局。跨场泛化能力**未验证**。

## 2. 裁切引入的先天偏差

- 本项目的输入是**按人工 bbox 裁出的单只猪**，而非原始整帧。
  这意味着：
  - 任务比"整帧多目标姿态识别"简单，指标**不可**与整帧检测任务的论文结果直接比较；
  - bbox 由数据集作者标注，若标注框偏紧或偏松，会影响模型可见的上下文。
- 同一源图的多个裁切被强制划入同一 split，避免近重复泄漏；但同帧样本仍共享
  光照、背景与相机视角，**统计独立性弱于同数量的独立拍摄图片**。

## 3. 模型依赖

- 全部结果依赖单一云端模型（默认 `glm-4.6v-flash`）与单一供应商。
  更换模型、甚至同一模型的版本更新，都可能改变结论。
- 因此实验元数据中记录了 `model_name`、提示词 SHA256、参数与时间戳；
  **跨版本结果不应合并为同一轮对照实验**（需求 6.3）。
- 免费模型可能存在限流、排队、静默降级等情况，本项目的响应时间包含网络与排队等待，
  **不等于**模型的纯推理时延。

## 4. 提示词实验的边界

- 三组提示词（A 基础 / B 定义 / C 定义+结构化+不确定性）只在本测试集上比较一次，
  **没有做多次重复实验**（可通过 `--repeats` 开启，但会增加调用量）。
  因此两组之间的小幅差异可能落在噪声范围内，不应过度解读。
- **实测结果**：A 0.377 / B 0.370 / C 0.330，三者差距（≤4.7 个百分点）在 200 样本上
  接近噪声量级。三组预测完全相同的样本占 85%，说明提示词改变的主要是**输出格式**，
  而不是**判断本身**。
- 一个反直觉的实测现象：定义最详细的 C 组准确率最低。可能原因是长定义强化了
  对 `lying_lateral` 的先验（C 组 179/200 预测为侧卧）。**不能据此断言"详细定义有害"**，
  只能说在本任务、本模型、本视角下没有带来收益。
- 只有 A 组的输出格式最宽松，其"准确率"与"JSON 有效率"受到**格式而非能力**的
  双重影响；报告中同时给出两个指标正是为了区分这一点，但仍难以完全解耦
  （本项目已改为"分类得分不要求 Schema 合规"以缓解该问题）。
- 提示词语言固定为中文，未测试英文提示词的影响。

## 4.1 模型行为的实测局限

- **拒答机制未生效**：C 组明确允许 `unknown`，但 600 次调用中拒答 0 次。
  说明"靠提示词实现不确定性门控"在本模型上不可行。
- **类别塌缩**：80%+ 的预测集中在 `lying_lateral`，`sitting` 一次未被预测。
  这是模型先验，不是提示词能纠正的问题。
- **视角是主要瓶颈**：裁切图为正上方俯拍，四肢常被躯干遮挡；
  目视复核显示部分误判样本在先验上确实难以单帧判断。

## 5. 指标口径的限制

- `unknown` 的处理：主指标使用"有效分类子集"口径，同时给出"严格口径"
  （拒答计为错误）与"无法判断比例"。**只看 Accuracy(有效) 会高估能力**，
  必须结合拒答率一起看。
- 混淆矩阵中"调用失败"的样本不计入任何格子，只在失败率里体现。
- 响应时间仅统计成功调用。
- 样本量较小时，Macro-F1 对少数类的波动非常敏感。

## 6. 明确不支持的能力

以下内容**不属于**本项目的功能，系统输出也**不应**被这样使用：

- ❌ 背膘厚、肌内脂肪、体重、体尺的测量或估计；
- ❌ 疾病诊断、健康状态判定、用药建议；
- ❌ 多目标检测与个体身份识别（ReID）；
- ❌ 实时视频流分析与多摄像头联动；
- ❌ 生产级养殖场系统的可靠性保证（本项目为课程原型）。

模型的 `description` 字段只是**可见体态的自然语言描述**，不是专业评估结论。

## 7. 工程与合规限制

- 图片会通过公网发送至第三方模型服务商处理。**不得上传未获授权的内部数据**。
- 使用的数据集为 CC BY 4.0，报告中已注明出处与引用；再分发时须保留署名。
- 运行环境为 Python 3.9（低于需求建议的 3.10），未使用 3.10+ 语法；
  未来升级解释器时需重新验证依赖兼容性。
- 未实现用户鉴权、多用户隔离、数据持久化数据库，仅适合单人本机使用。

## 8. 后续改进方向

1. 扩大到 unseen-VP 划分，量化跨相机视角的泛化损失；
2. 对 `sitting` 类做定向过采样，或在报告中给出自助法置信区间；
3. 引入第二次人工复核，报告标注一致性（Cohen's κ）；
4. 用 `--repeats` 做稳定性实验，区分"能力差异"与"采样噪声"；
5. 增加一个更强/更弱的对照模型，观察提示词收益是否依赖模型能力；
6. 把整帧多目标场景接入（需要目标检测，属于另一个任务）。
