## 3. 模型 API
| 项 | 核查结果 | 来源 |
|---|---|---|
| 首选服务商 | 智谱开放平台（BigModel） | https://open.bigmodel.cn |
| 首选模型 | glm-4.6v-flash，官方定价页标注「免费」，128K 上下文 / 32K 最大输出 | https://docs.bigmodel.cn/cn/guide/start/pricing.md 、 https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash.md |
| 备选服务商/模型 | 阿里云百炼 qwen3-vl-plus，视觉理解模型有 100 万 Token 免费额度（开通后 90 天，限北京/新加坡地域） | https://help.aliyun.com/zh/model-studio/vision |
| 接口形式 | OpenAI 兼容：POST https://open.bigmodel.cn/api/paas/v4/chat/completions，Authorization: Bearer <key> | 同上 |
| 图片输入方式 | content 数组内 {"type": "imageurl", "imageurl": {"url": "data:image/jpeg;base64,..."}}，官方示例含 Base64 上传 | 智谱 GLM-4.6V-Flash 文档 |
| 图片格式限制（百炼侧） | JPEG/JPG/PNG/BMP；宽高均 >10px；长宽比 ≤200:1；Base64 编码前 ≤20MB | https://help.aliyun.com/zh/model-studio/vision |
| 视觉 Token 估算 | Qwen3-VL 系列每 Token 对应 32×32 像素；图像 Token = h̄·w̄/(32×32)+2 | 同上 |
| 原生结构化输出 | 视觉理解接口未提供 JSON Schema 约束（未见 response_format 相关说明） | 同上 |
| 端点可达性（本机实测） | 未带密钥 POST 两个端点均返回 HTTP 401（说明网络可达、仅缺授权） | 本机实测 |
| 密钥配置 | .env + 环境变量；.env.example 仅放占位符，.env 已加入 .gitignore | 本项目实现 |
| 密钥现状 | 环境变量与全盘 .env 均无任何模型密钥 | 本机实测 |
结论：§9.1 第 4、5 步（真实试调用）当前无法完成——缺少密钥。这是唯一的硬阻塞。
其余（接口形式、图片传入方式、认证方式、限制、成本）均已核实。
## 4. 数据集
| 项 | 核查结果 |
|---|---|
| 数据集 | anilbhujel/viewpoint-aware-pig-posture-recognition（HuggingFace，public，gated=false） |
| 许可 | CC BY 4.0（README 正文与 card 元数据一致），允许课程研究使用，须署名引用 |
| 规模 | 全库 Train 22,933 实例/3,090 图；seen-VP test 2,603 实例/300 图；unseen-VP test 11,708 实例/1,350 图 |
| 标签类型 | 逐实例 bbox([x,y,w,h]) + class_id(0–4) + 相机视角角（方位角/仰角） |
| 类别 | 0 Laterallyingleft、1 Laterallyingright、2 Sitting、3 Standing、4 Sternal_lying |
| 类别分布（seen-VP test） | Standing 1261、Sternal 712、LateralR 293、LateralL 267、Sitting 70（2.7%） |
| 图片规格 | 鱼眼 1280×720、Orbbec 1920×1080；实测单图 ≈180 KB（image/jpeg） |
| 下载可行性 | resolve 直连返回 HTTP 200，无需鉴权；镜像 hf-mirror.com 可用（主站间歇不可达） |
| 裁剪尺寸实测 | bbox 中位数 225×213 px，最小 37×76，最大 609×539 → 必须加质量过滤 |
| 独立性 | 只使用官方 seen-VP 测试划分；同一源图的裁切整组进入同一 split，避免近重复泄漏 |
类别映射（写入 src/schema.py）：0,1 → lyinglateral；2 → sitting；3 → standing；4 → lyingother。
## 5. 成本估算
| 项 | 估算 |
|---|---|
| 单张图片送入尺寸 | 长边缩放到 512px，背景补边 |
| 单次调用输入 Token | 视觉 ≈ 258（512×512/(32×32)+2）+ 文本 ≈ 400–600（B/C 组较长） |
| 单次调用输出 Token | ≈ 80–150（关闭思考链后） |
| 单次合计 | ≈ 800–1000 Token |
| 主实验规模 | 3 组提示词 × 约 150 条测试样本 = 450 次调用 |
| 总 Token | ≈ 36 万–45 万 |
| 现金成本 | ¥0：glm-4.6v-flash 官方标注免费；若改用 qwen3-vl-plus，该用量也在 100 万 Token 免费额度内 |
| 保底措施 | 运行器内置 PIGMAXCALLS 硬上限（默认 1200）+ 逐条落盘断点续跑 |
声明：以上为估算。真实用量以 API 返回的 usage 字段为准，实验脚本会把
inputtokens/outputtokens 逐条记录到原始 CSV 中。
