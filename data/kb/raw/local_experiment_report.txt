# 实验报告：提示词设计对多模态大模型猪只姿态识别的影响
实验已完成。本报告所有数字均由 results/raw/testmainv2_raw.csv（600 条真实调用记录）
经 scripts/plot_results.py 计算得到，可用同一命令复算。
生成日期：2026-10-19
## 0. 结论速览
| 研究问题 | 结论 |
|---|---|
| RQ1 大模型能否识别猪只姿态？ | 能力有限。最佳方案准确率 37.7%，仅略高于四分类随机水平 25%，Macro-F1 仅 0.232 |
| RQ2 明确姿态定义能否提升表现？ | 不能。B 组（0.370）与 A 组（0.377）几乎无差异（差 0.7 个百分点） |
| RQ3 强制 JSON + 允许拒答能否改善可靠性？ | 一半成功：JSON 有效率从 0% 提升到 99.5%；但模型一次拒答都没有使用（unknown 率 0%） |
| RQ4 典型错误与边界？ | 模型存在严重的"侧卧"先验（80%+ 预测为 lying_lateral），sitting 一次未预测，standing 召回率仅 13–28% |
最重要的发现是一个负面结果：增加提示词约束能显著改善输出格式，
但没有改善、甚至略微降低了分类准确率（C 组最低）。
## 1. 实验目的与研究问题
比较三组提示词设计对猪只姿态识别的影响，区分三个维度：
分类正确性（Accuracy / Macro-F1）
结构化输出质量（JSON 有效率）
不确定性处理（拒答率）

## 9. 结果分析与讨论
## 9.1 RQ1：模型能否识别姿态？——能力有限
四分类随机水平 25%，三个方案分别为 37.7% / 37.0% / 33.0%，
只比随机猜测好一点；Macro-F1 0.167–0.232 也说明各类别表现极不均衡。
但要注意：这不等于模型"看不懂猪"。从 description 字段看，
模型对画面的描述大体合理（"身体侧面贴地，躯干呈水平姿态"），
它的问题在于类别判别粒度，而不是完全无法理解图像。
## 9.2 RQ2：明确姿态定义有用吗？——没有
A（0.377）vs B（0.370）相差 0.7 个百分点，在 200 样本上属于噪声范围
（单个样本约 0.5 个百分点）。混淆矩阵显示两者的错误模式几乎相同。
合理的解释：模型已经把猪识别为"躺着的猪"，但**从俯视鱼眼视角无法可靠区分
站立 / 侧卧 / 俯卧**——这些区分依赖地面接触、腿部伸展、阴影等线索，
而裁切图是正上方俯拍，腿常被躯干遮挡。增加文字定义无法弥补视觉证据的缺失。
## 9.3 RQ3：JSON 约束与拒答规则——一半成功
格式方面：完全成功。 JSON 有效率从 0%（A/B）提升到 99.5%（C，199/200）。
说明"明确字段 + 只许 JSON + 禁止多余文字"这套约束对输出格式非常有效。
不确定性处理：完全失败。 C 组明确允许在证据不足时返回 unknown，
但 600 次调用中 uncertain=true 出现 0 次，unknown 预测 0 次。
模型宁可给一个（很可能错的）具体类别，也不愿拒答。
这一点很重要：提示词能约束格式，但约束不了"诚实"。
若要用拒答机制做质量门控，可能需要更强的干预（如前置置信度阈值、
两阶段调用、或改用支持结构化置信度的接口），单靠提示词不可靠。
## 9.4 RQ4：为什么 C 组更差？
C 组准确率最低（0.330），且 standing 召回从 28.2%（A）掉到 12.8%。
一个可能的原因是长定义带来的锚定效应：C 组对 lying_lateral 的描述较详细
（"身体一侧着地，躯干长轴大致水平贴地，通常可见一侧体侧"），
与俯视图下的猪体外形高度吻合，模型更容易把所有猪都判成侧卧
（预测分布：A 159 → B 161 → C 179 条 lying_lateral）。
这是"提示词越详细越好"这一直觉的反例：更长的定义可能强化错误的视觉先验。
## 9.5 三组一致性
三组预测完全相同的样本占 170/200（85%）；A 与 B 不同的仅 19 条，
A 与 C 不同的 21 条。提示词改变的主要是格式，而不是判断。
这与 8.1 中三者准确率接近、8.3 中混淆模式雷同的观察一致。
## 10. 典型错误案例
| 错误类型 | 典型表现 | 数量（C 组） |
|---|---|---:|
| 站立 → 侧卧 | 站立猪被判成侧卧，模型描述"身体一侧贴地" | 67 / 78 |
| 俯卧 → 侧卧 | 胸腹着地被判成侧卧 | 43 / 47 |
| 坐姿 → 侧卧 | 坐姿样本无一判对 | 13 / 13 |
| 侧卧 → 站立 | 反向误判，较少 | 6 / 62 |
| 完全无法解析 | 一次未能抽出任何类别 | 1 / 600 |
目视复核两张被判为侧卧的"站立"样本（testpen1turcam2202509210517260003/0004）：
从正上方俯拍，猪体轮廓呈长条贴地状，四肢几乎不可见，其中后者仅 158×104 像素。
在这种视角与分辨率下，人类标注者如果不借助时间上下文与地面阴影，也很难仅凭单帧判断站立与否。
这说明部分错误源于任务本身在俯视图下的不可辨识性，不能全部归咎于模型。
## 11. 实验局限性
1. 样本量小：200 条测试样本，sitting 仅 13 条；单样本约 0.5 个百分点，
A/B 之间 0.7 个百分点的差异不能视为真实差异；
2. 单次运行：未做重复实验，无法区分"能力差异"与"采样噪声"（可用 --repeats）；
3. 单一模型：结论只适用于 glm-4.1v-thinking-flash，不能外推到其它 VLM；
4. 裁切输入 + 俯视视角：任务难度被视角放大，指标不可与整帧多目标研究直接比较；
5. 标签来源：使用数据集作者标注，未做二次人工核验，未计算标注一致性 κ；
6. 免费模型：限流与排队影响响应时间（p95 达 8.9s），但不影响分类结果的正确性判断；
7. 二次解析：修正解析器后重算了指标，虽然只改文本抽取、未改原始返回，
但严格来说初版与修正版的数字不同，已在第 7 节完整披露。
## 12. 结论与改进方向
结论
1. 在俯视鱼眼视角的单猪裁切图上，该视觉大模型的姿态识别准确率为 33%–38%，
仅略高于 25% 的随机水平，不足以支撑生产使用；
2. 提示词中增加类别定义没有提升准确率（RQ2 否定），
过度详细的定义甚至可能强化错误先验（C 组最差）；
3. 提示词能有效约束输出格式（JSON 有效率 0% → 99.5%），
但无法诱导模型诚实拒答（拒答率 0%）——格式可控、可靠性不可控；
4. 主要错误集中在"站立/俯卧 → 侧卧"的单向塌缩，源自俯视图下姿态线索不足。
改进方向
1. 换用包含侧视/斜视角度的数据（如数据集的 Orbbec 机位）或 unseen-VP 划分，
检验视角是否是主要瓶颈；
2. 提供上下文（如同一场景的多帧、或标注框外的地面阴影）帮助判别；
3. 用 --repeats 做重复实验并给出置信区间，而非单次比较；
4. 引入"置信度阈值 + 两阶段复核"替代纯提示词的拒答机制；
5. 增加第二标注者计算 κ，区分"模型错"与"标签有争议"；
6. 把"能否拒答"作为独立实验（例如强制二选一 vs 允许 unknown）单独检验。
